# 光合作用是怎么回事

光合作用是绿色植物最重要的生理活动之一。简单说，光合作用就是植物利用光能，把二氧化碳和水合成为有机物（主要是葡萄糖），并释放出氧气的过程。这个过程主要在植物的叶绿体里进行，叶绿体中含有叶绿素，叶绿素能吸收太阳光，尤其是红光和蓝紫光，而绿光基本不被吸收，所以叶子看起来是绿色的。

光合作用可以分为两个阶段：光反应阶段和暗反应阶段。光反应阶段需要光照，发生在叶绿体的类囊体薄膜上，它把光能转化为化学能，储存在ATP中，同时把水分解，释放出氧气，并产生氢（还原剂）。暗反应阶段不需要光，发生在叶绿体的基质中，它利用光反应产生的ATP和氢，把二氧化碳固定并还原成有机物（葡萄糖）。

光合作用的总反应式可以写作：二氧化碳 + 水 ——(光能、叶绿体)——> 葡萄糖 + 氧气。从反应式看，光合作用把无机物变成了有机物，把光能储存在了有机物中的化学能里。

光合作用的原料是二氧化碳和水，产物是葡萄糖和氧气。光合作用不仅为植物自身制造养料，还为整个地球上的生命提供了氧气来源和有机物基础，可以说是生态系统能量流动的起点。

影响光合作用的因素主要有光照强度、二氧化碳浓度和温度。光照越强，光合速率在一定范围内越快，但超过一定限度后速率不再增加；二氧化碳是原料之一，浓度越高，光合速率在一定范围内越快；温度影响酶的活性，过高或过低都会降低光合速率。

叶片是植物进行光合作用的主要器官。叶片上的气孔是二氧化碳和氧气进出的大门，也是水分散失的通道。白天气孔张开，有利于二氧化碳进入和氧气放出。
