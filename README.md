# make-knowledge-cards

把一段文章或本地 Markdown/TXT 文件，提炼成 **5\~8 张结构化知识卡片**，便于学习、复习与整理。每张卡片包含：**标题、核心知识、简明解释、例子或自测问题**。

> 由官方 Skill 初始化工具（
>
> `skill-creator-for-work`
>
> ）创建并校验。

## 项目解决什么问题



* **信息太多、抓不住重点**：阅读长文后难以快速提炼核心要点。本 Skill 自动识别文章里真正重要的知识，而不是堆砌所有句子。

* **复习材料难整理**：手写笔记往往把多个知识点揉在一起。本 Skill 强制**一张卡片只讲一个知识点**，产出结构统一、可直接复习的卡片。

* **防止 “注水” 与 “失真”**：只输出原文确实包含的知识，**不编造原文没有的事实**；信息不足时**不强行凑满数量**，宁可少也不注水。

## 主要功能



* 提取文章中**真正重要**的知识点，过滤琐碎与重复内容。

* **一张卡片只讲一个知识点**，避免信息堆叠。

* 每张卡片固定四字段：**标题、核心知识、简明解释、例子或自测问题**。

* 自动**去重、合并**含义重复的内容。

* 所有内容**严格来自原文**，解释与例子也不引入原文未支持的新事实。

* 信息不足时**按实际知识点数量输出**，不为凑 5\~8 张而拆分或注水。

* 输出为标准 Markdown，可直接复制到笔记软件。

### 不支持



* ❌ 网页抓取（不访问链接，请粘贴文本）

* ❌ PDF / Word 等其他格式（只处理纯文本与本地 `.md` / `.txt`）

* ❌ Anki 导出（不生成 `.apkg`）

* ❌ 图形界面 / 图片卡片生成

## 安装方法

本产品是一个 **AI Agent Skill**，需要放入 Agent 能自动发现并加载的 Skill 目录后使用。



1. **定位目标目录**：找到你所用 Agent 环境的 Skill 根目录（常见为 `workspace/.user_skills/` 或其它已配置的 skills 目录）。

2. **复制文件夹**：把 `skills/make-knowledge-cards/` 整个文件夹复制到该目录下，最终路径形如：



```
<workspace>/.user_skills/make-knowledge-cards/
├── SKILL.md
└── agents/openai.yaml
```



1. **确认加载**：重启 / 刷新 Agent 会话，或直接输入触发语句测试是否生效。

2. **验证安装**（可选）：用官方校验脚本检查 Skill 结构是否合法：



```
python <skill-creator>/scripts/quick_validate.py skills/make-knowledge-cards
```

输出 `Skill is valid!` 即通过。

> 说明：本 Skill 为纯指令型，无附带脚本或第三方依赖，复制即可用，无需额外安装 Python 包。

## 使用方法



1. 在支持 Skill 的 Agent 环境中加载本 Skill（Skill 名：`make-knowledge-cards`）。

2. 直接说 “把下面这篇文章做成知识卡片”，并**粘贴正文**；或提供一个本地 `.md` / `.txt` 文件的路径。

3. Agent 按 SKILL.md 工作流生成卡片。

### 输入方式



```
（粘贴一篇文章，或给出本地文件路径，如 C:\notes\光合作用.md）
```

### 输入示例（粘贴文章）



```
# 水的三种状态
水在自然界中通常以三种状态存在：固态、液态和气态。固态水就是我们常见的冰……
```

### 输出示例（知识卡片）



```
# 知识卡片：水的三种状态

## 卡片 1｜水的三种状态
- **核心知识**：水以固态（冰）、液态、气态（水蒸气）三种状态存在。
- **简明解释**：固态是冰，温度降到 0℃ 以下形成；液态是常温最常见的江河湖海之水；气态是水受热蒸发形成的水蒸气。
- **自测问题**：水蒸气属于水的哪种状态？答案：气态。

## 卡片 2｜三种状态的相互转化
- **核心知识**：三种状态可相互转化：冰融化、水沸腾成水蒸气、水蒸气凝结成水滴、水滴凝固成冰。
- **简明解释**：加热使冰→水→水蒸气（吸热过程）；降温使水蒸气→水滴→冰（放热过程）。
- **例子**：烧水时水变成水蒸气（蒸发），杯盖上的水滴就是水蒸气遇冷凝结成的。

> 说明：原文信息量有限，仅提炼出 2 个独立知识点，按“不强行凑数”原则只输出 2 张卡片。
```
